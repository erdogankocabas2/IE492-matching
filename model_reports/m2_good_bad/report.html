Good–Bad: τ-threshold matching

İki skill sınıfı. Oyuncu önce kendi sınıfıyla eşleşir; τ kadar bekleyen karşı sınıfla da eşleşebilir. τ, match quality ile waiting time arasındaki dengeyi ayarlıyor.

Arrivals
Poisson(λ); p olasılıkla Good, 1 − p Bad.
Policy
(1) Same-class priority: aynı sınıfta bekleyen varsa anında eşleşir. (2) W ≥ τ olan oyuncu karşı sınıfın sıra başıyla eşleşir.
Abandonment
Sabır ~ Exp(θi), sınıfa göre farklı. Kapalıyken Phase 2.1.
State
NG, NB ∈ {0, 1} ve bekleyenin yaşı.
Metrics
WG, WB, W · LG, LB, L · P(abandoni) · cross-match rate
Source
m2_good_bad/simulation.py · kurallar phase2_1 / phase2_2 ile aynı

§3

Analytical model & validation

Ara τ için kapalı form yok; iki uç noktada zincir küçük ve çözülebilir.

StructureNi(t) ∈ {0, 1} ⇒ N(t) ≤ 2; state = (N1, …, N2, bekleyenlerin yaşı)
τ = ∞ · separate classes0 → 1 : λi, 1 → 0 : λi + θi ⇒ Li = λi / (2λi + θi), Wi = 1 / (2λi + θi)
τ = 0 · single pool0 → i : λi, i → 0 : λ + θi ⇒ πi ∝ λi / (λ + θi), cross = Σ πi(λ − λi) / (λ Σ πi)
Little's lawLi = λiWi, P(abandoni) = θiLi / λi; θ = 0 ⇒ cross = 1 − Σpi2

0 < τ < ∞ için τ deterministik; sayılarla kurulan zincir Markov değil. Ara τ değerleri simülasyonla, uç noktalar formülle.

Validation at end points

Simülasyonun τ = 0 ve τ = ∞ run'ları ile kapalı form.
