Chess: White vs Black

Her oyuncu bir renk ister ve yalnızca karşı renkle eşleşir. Aynı anda tek renk bekleyebilir. Soru: talep dengesizken kim ne kadar bekler, kaçı ayrılır?

Arrivals
Poisson(λ); p olasılıkla White, 1 − p Black.
Policy
FCFS: karşı renkte bekleyen varsa sıra başıyla anında eşleşir, yoksa kuyruğa girer.
Abandonment
Sabır ~ Exp(θ); açılıp kapatılabilir.
State
X(t) = Nw − Nb, ℤ üzerinde birth–death CTMC.
Metrics
Ww, Wb, W · Lw, Lb, L · P(abandoni) · P90, P(W = 0)

§3

Analytical model & validation

X(t) bir birth–death zinciri; steady-state dağılımı kapalı formda.

Transition ratesn → n+1 : pλ,   n → n−1 : (1−p)λ + nθ   (n > 0; n < 0 simetrik)
Steady stateπn = π0 ∏k=1..n pλ / ((1−p)λ + kθ),   n > 0
Little's lawLw = Σn>0 nπn,   Ww = Lw / (pλ),   P(abandonw) = θLw / (pλ)
Stabilityθ > 0 ⇒ positive recurrent;   θ = 0: p = ½ null-recurrent, p ≠ ½ transient;   P(abandonmajority) ≥ (2p−1)/p
